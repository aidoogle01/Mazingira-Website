# FactStrip

The facts at the top of a trip page, between hairlines, directly under the title.

- Provide: `duration_days`, `best_time`, `start` and `locations` from the trip file, written as plain phrases ("June to September", not "JUN–SEP").
- Labels are sentence case in `ink-muted`; there are no all-caps labels anywhere in the system.
- The places must match the itinerary; the content validator checks this.
